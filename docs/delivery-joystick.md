# 배달 조이스틱

기존 `/games/delivery`에서 하단 방향 버튼을 이동형 반투명 조이스틱 하나로 교체했습니다. 도로·카메라 설정·브랜드·충돌·진입로·배달 규칙은 변경하지 않습니다.

- 상단 길안내·일시정지 영역을 제외한 조이스틱 쪽 절반 어디서나 터치/마우스 드래그를 시작합니다. 처음 누른 위치가 조이스틱의 중심이며, 누르기만 하면 움직이지 않습니다. 손을 놓으면 조이스틱이 사라지고 다음 터치 위치에 새로 나타납니다. 화면 가장자리에서도 입력 중심은 실제 터치 위치이며, 원의 일부는 화면 경계에서 잘릴 수 있습니다.

- 위/아래로 밀어 누르는 동안 전진/후진합니다. 기존 가속·감속·최고 속도를 사용하며, 자동 전진이나 아날로그 속도 조절은 추가하지 않습니다.
- 좌우로 한 번 밀면 인접한 한 차선으로 이동합니다. 대각선으로 밀면 달리면서 변경합니다. 옆으로 계속 밀어도 반복 이동하지 않습니다. 손가락을 위쪽(가로축 중앙)으로 되돌렸다가 다시 옆으로 밀면 전진을 유지하며 다음 차선으로 옮깁니다.
- 중앙 여유 영역과 입력·해제 임계값을 분리해 미세한 손떨림에 반응하지 않습니다.
- 첫 손가락만 조이스틱을 소유합니다. 추가 손가락은 방향을 빼앗거나 기존 입력을 해제하지 않습니다. 손을 떼면 감속 정지합니다.
- 조이스틱을 잡은 채 다른 손가락으로 상단 일시정지를 눌러도 멈춥니다. 두 번째 터치에 클릭 이벤트를 생성하지 않는 모바일 브라우저를 위해 해당 버튼의 터치 해제를 별도로 처리하고, 클릭이 함께 오는 경우 중복 실행하지 않습니다.
- 원 밖으로 크게 드래그해도 포인터 캡처로 입력을 유지합니다. 손잡이 그림만 원 안에 제한하며, 처음 터치한 중심은 따라 움직이지 않습니다. 상단에서 시작한 터치를 주행 화면으로 끌어와도 조작이 시작되지 않습니다. 취소·캡처 상실·창 포커스 이탈·화면 크기 변경·일시정지·탭 숨김·퀴즈·도착·재시작에서 입력을 초기화합니다. 해제된 손가락을 계속 움직여도 자동 재개하지 않으며 새 터치가 필요합니다.
- 시작·일시정지·퀴즈·구매 광고 화면에서는 입력 면을 비활성화해 화면의 버튼만 동작합니다. 조이스틱 입력 면은 길안내 아래의 주행 화면에만 겹쳐져 UI 버튼을 가로채지 않습니다.
- 집 앞 길에서는 좌우 조향이 비활성화되지만 후진은 가능합니다. PC 화살표·마우스 드래그를 지원하며 키보드와 조이스틱으로 전후진을 동시에 입력하면 정지합니다.
- 집 앞 길 끝이나 미배달 상태로 큰길 끝에 정차했을 때, 새 조이스틱의 중립 터치를 매 프레임 취소하지 않습니다. 끝에 도달한 전진 입력은 해제하되 새 터치를 아래로 끌어 후진할 수 있습니다. 퀴즈·완료 상태의 입력 차단과 배달 대기 시간은 유지합니다.
- 실제 조작 설명은 스크린리더에만 제공하고 터치 중인 원에만 화살표 아이콘을 표시합니다. 새 안내 팝업은 없습니다.

## 조작 위치와 점프 (2026-10 변경)

- 기본은 **오른손 이동, 왼손 점프**입니다. 주행 화면을 반으로 나눠 오른쪽 절반이 조이스틱, 왼쪽 절반은 아무 곳이나 탭하면 점프합니다. PC는 스페이스바로 점프합니다.
- 일시정지 메뉴의 **조작 설정**에서 "왼손 이동·오른손 점프"로 바꿀 수 있고, 선택은 이 기기 브라우저에 저장됩니다(저장이 막힌 환경에서는 기본값).
- 점프 쪽 아래 구석의 반투명 원은 안내 표시이고, 실제로는 그 쪽 절반 전체가 점프 영역입니다. 두 영역은 별도 터치 대상이라 한 손으로 달리면서 다른 손으로 점프해도 서로 끊기지 않습니다.
- 조이스틱 반경은 링의 36%(기존 30%), 전진 해제 지점은 10%(기존 17%)입니다. 링은 처음 누른 자리에 고정되고(따라 올라가지 않음), 쭉 밀다가 살짝 되돌아와도 중심 근처까지 내려오기 전에는 전진이 끊기지 않습니다.
- 배달 골목 안에 들어가면 아직 배달하지 않은 집 앞 배달 칸 가운데에서 자동으로 감속·정차하고 퀴즈가 열립니다(전진을 누르고 있어도). 배달을 건너뛰려면 골목에 들어가지 않고 큰길로 지나가면 됩니다. 감속 세기: `DELIVERY_GAME_CONFIG.deliveryAutoBrakePerSecond`.
- 점프용 장애물은 큰길 11개, 우회로 양쪽 각 2개입니다(세 차선 전체를 막는 것: 410·840m). 기존 일반 장애물 8개는 그대로입니다.
- **우유 부스터**(`components/delivery/delivery-pickups.ts`): 길 위에 우유병 6개(160·455·735·897m, 우회로 각 618m). 지나가면 3초간 최고속도 1.35배, 시야 확대·진한 속도선, "우유 부스터!" 표시. 부딪히면 즉시 끝납니다. 이 판 안에서만의 효과이며 포인트·보상이 아닙니다.
- **도로 붕괴 + 점프대**: 283m, 우회로 양쪽 590m, 864m에 길 전체(모든 차선)가 무너진 17m 구간이 있고, 바로 앞 가운데 차선에만 점프대가 있습니다. 32m 앞 표지판이 "가운데 점프대로"를 알려줍니다.
  - 점프대를 밟으면 속도를 19~21m/s로 맞추고 공중에서는 그대로 유지해, 항상 약 20m를 날아 같은 자리에 착지합니다. 일반 점프(최고속도 15m)로는 못 건넙니다.
  - 점프대 비행 구간과 착지 후 8m에는 다른 장애물·움직이는 장애물을 두지 않아, 점프대로 장애물을 건너뛰지 않습니다(`scripts/test-delivery-pickups.ts`에서 검사).
  - 점프대를 못 타고 붕괴 구간에 들어가면 자전거가 빠지고 약 1초 뒤 구간 16m 앞 가운데 차선에서 정지 상태로 다시 시작합니다.
- **우유 신선도와 별점**(`components/delivery/delivery-freshness.ts`): 길안내 카드 아래 막대가 주행 시간만큼 줄어듭니다(160초면 0, 퀴즈·일시정지 시간은 제외). 부딪히면 3초, 붕괴 구간에 떨어지면 6초가 추가로 깎이고 화면에 "앗! −3초"가 뜹니다. 완료 화면 별: 신선도 50% 이상이고 4곳 모두 배달하면 ★3, 25% 이상이면 ★2, 그 외 ★1(완주하면 최소 1개). 이 판의 기록일 뿐 포인트·보상이 아닙니다.
- **구간**: 1구간 점프 연습 → 2구간 무너진 도로 → 3구간 갈림길 앞 직선 → 4구간 우회로 질주 → 5구간 움직이는 장애물 → 마지막 구간. 들어설 때 구간 이름이 잠깐 뜹니다. 첫 구간은 장애물을 줄여 연습용으로 두었습니다.
- **손맛**: 점프로 장애물·고양이·공·오리를 넘으면 "좋아!"와 반짝임, 점프대 착지는 "착지 성공!". 부딪히면 자전거가 좌우로 휘청이고 먼지가 일며, 점프대 착지에도 먼지가 납니다. 장애물은 둥근 모서리의 밝은 색으로 바꾸고 25% 높고 깊게 키웠습니다(폭은 그대로).
- **색감**: 톤매핑을 Neutral로 바꾸고(ACES는 파스텔을 회색빛으로 만듦) 노출·하늘·안개·조명을 밝게 조정했습니다. 건물 형태는 그대로입니다.
- **길 위 이벤트**: 오리 가족(952m, 아파트 직전)이 오른쪽에서 왼쪽으로 천천히 건넙니다(점프 가능, 멈춰서 기다려도 됨). 비둘기 떼(158m, 790m)는 길에 앉아 있다가 자전거가 다가오면 날아오릅니다(부딪힘 없음).
- 움직이는 장애물(`components/delivery/delivery-movers.ts`)은 3개입니다. 자전거가 일정 거리에 오면 움직이기 시작하고, 그 전부터 화면에 보입니다.
  - 비치볼(약 255m, 지름 1.5m): 오른쪽 인도에서 굴러 나와 자전거 쪽으로 대각선으로 차선을 가로지르며 통통 튑니다. 점프로 넘거나 피합니다.
  - 버스(약 726m): 오른쪽 정류장에서 깜빡이를 2초 켠 뒤 3차선으로 들어와 천천히 달리고, 800m 전에 다시 버스 차선으로 빠집니다. 점프로는 못 넘고 왼쪽 차선으로 피합니다.
  - 고양이(약 910m): 왼쪽 인도에서 오른쪽으로 천천히 길을 건넙니다. 점프하거나, 멈춰서 기다리면 됩니다.
  - 점프는 높이 1.5m·체공 0.75초입니다.
  - 부딪히면 정적 장애물과 같이 잠깐 감속만 됩니다. 멈춰 있는 자전거는 부딪히지 않으며, 판정 폭은 모델보다 약간 좁게 잡았습니다(쉬운 난이도).
- 손맛 연출: 최고속도 근처에서 시야가 아주 조금(2.5°) 넓어지고 화면 가장자리에 옅은 속도선이 나타납니다. 충돌 때만 화면이 살짝 내려앉았다 돌아옵니다(착지 흔들림은 덜컹거림이 강해 제거).
- 장애물에 부딪히면 속도가 60%로 줄고(기존 38%), 1초간 최고 11m/s로 제한됩니다(기존 7.5m/s). 장애물이 늘어난 만큼 멈칫거림을 줄였습니다. 기기의 "동작 줄이기" 설정이 켜져 있으면 시야 변화·흔들림을 하지 않습니다.
- 소리·진동(`components/delivery/delivery-sound.ts`): 점프·착지·충돌·배달 효과음과 가벼운 배경음을 코드로 합성합니다(음원 파일·라이선스 없음). 진동은 지원하는 기기(주로 안드로이드)에서만 됩니다. 기본은 켜짐이고, 일시정지 메뉴의 "소리·진동" 버튼으로 끄면 이 기기에 저장됩니다. 브라우저 정책상 소리는 "배달 출발"을 누른 뒤부터 납니다.
- 모바일 주소창이 나타나거나 사라질 때 생기는 화면 높이 변화로는 조작을 끊지 않습니다. 화면 폭이 바뀔 때(회전)만 초기화합니다.
- 점프 높이·체공 시간, 장애물별 통과 높이는 `components/delivery/delivery-jump.ts`, 점프용 장애물 배치는 `data/delivery-game.ts`의 `jump-*` 항목입니다.

## 수정 위치

- `components/delivery/DeliveryJoystick.tsx`: 포인터 소유·캡처·해제와 손잡이 표시
- `components/delivery/delivery-joystick.ts`: `JOYSTICK_CONFIG`의 손잡이 이동 반경, 중앙 여유 영역, 차선 변경/재활성화 임계값
- `components/delivery/DeliveryGame.module.css`: `.playArea`, `.joystickControls`, `.joystickVisual`, `.joystick*`의 입력 범위·크기·투명도
- `components/delivery/DeliveryGame.tsx`: 기존 입력 상태에 조이스틱 연결

검증: `pnpm exec tsx scripts/test-delivery-joystick.ts`는 순수 입력 규칙을 검사합니다. `node scripts/qa-delivery-game.mjs`는 실제 브라우저 터치와 마우스로 입력·취소·대각선·추가 손가락 격리를 확인하고, 세 집 배달·우회·완료·재시작까지 진행합니다. 모바일 크기 에뮬레이션 검증이며 실제 iOS/Android 기기 검수와는 구분합니다.
