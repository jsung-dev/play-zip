# 배달 조이스틱

기존 `/games/delivery`에서 하단 방향 버튼을 이동형 반투명 조이스틱 하나로 교체했습니다. 도로·카메라 설정·브랜드·충돌·진입로·배달 규칙은 변경하지 않습니다.

- 상단 길안내·일시정지 영역을 제외한 주행 화면 어디서나 터치/마우스 드래그를 시작합니다. 처음 누른 위치가 조이스틱의 중심이며, 누르기만 하면 움직이지 않습니다. 손을 놓으면 조이스틱이 사라지고 다음 터치 위치에 새로 나타납니다. 화면 가장자리에서도 입력 중심은 실제 터치 위치이며, 원의 일부는 화면 경계에서 잘릴 수 있습니다.

- 위/아래로 밀어 누르는 동안 전진/후진합니다. 기존 가속·감속·최고 속도를 사용하며, 자동 전진이나 아날로그 속도 조절은 추가하지 않습니다.
- 좌우로 한 번 밀면 인접한 한 차선으로 이동합니다. 대각선으로 밀면 달리면서 변경합니다. 옆으로 계속 밀어도 반복 이동하지 않습니다. 손가락을 위쪽(가로축 중앙)으로 되돌렸다가 다시 옆으로 밀면 전진을 유지하며 다음 차선으로 옮깁니다.
- 중앙 여유 영역과 입력·해제 임계값을 분리해 미세한 손떨림에 반응하지 않습니다.
- 첫 손가락만 조이스틱을 소유합니다. 추가 손가락은 방향을 빼앗거나 기존 입력을 해제하지 않습니다. 손을 떼면 감속 정지합니다.
- 조이스틱을 잡은 채 다른 손가락으로 상단 일시정지를 눌러도 멈춥니다. 두 번째 터치에 클릭 이벤트를 생성하지 않는 모바일 브라우저를 위해 해당 버튼의 터치 해제를 별도로 처리하고, 클릭이 함께 오는 경우 중복 실행하지 않습니다.
- 원 밖으로 크게 드래그해도 포인터 캡처로 입력을 유지합니다. 손잡이 그림만 원 안에 제한하며, 처음 터치한 중심은 따라 움직이지 않습니다. 상단에서 시작한 터치를 주행 화면으로 끌어와도 조작이 시작되지 않습니다. 취소·캡처 상실·창 포커스 이탈·화면 크기 변경·일시정지·탭 숨김·퀴즈·도착·재시작에서 입력을 초기화합니다. 해제된 손가락을 계속 움직여도 자동 재개하지 않으며 새 터치가 필요합니다.
- 시작·일시정지·퀴즈·구매 광고 화면에서는 입력 면을 비활성화해 화면의 버튼만 동작합니다. 조이스틱 입력 면은 길안내 아래의 주행 화면에만 겹쳐져 UI 버튼을 가로채지 않습니다.
- 집 앞 길에서는 좌우 조향이 비활성화되지만 후진은 가능합니다. PC 화살표·마우스 드래그를 지원하며 키보드와 조이스틱으로 전후진을 동시에 입력하면 정지합니다.
- 집 앞 길 끝이나 미배달 상태로 큰길 끝에 정차했을 때, 새 조이스틱의 중립 터치를 매 프레임 취소하지 않습니다. 끝에 도달한 전진 입력은 해제하되 새 터치를 아래로 끌어 후진할 수 있습니다. 퀴즈·완료 상태의 입력 차단과 배달 대기 시간은 유지합니다.
- 실제 조작 설명은 스크린리더에만 제공하고 터치 중인 원에만 화살표 아이콘을 표시합니다. 새 안내 팝업은 없습니다.

## 점프

- 주행 화면 오른쪽 아래의 반투명 원형 버튼을 누르는 순간(손을 뗄 때가 아님) 한 번 뜁니다. PC는 스페이스바입니다. 체공 약 0.7초, 이중 점프 없음, 공중에서도 전후진·차선 조작은 그대로입니다.
- 버튼은 조이스틱 입력 면 위에 있는 별도 포인터 대상이라, 한 손가락으로 조이스틱을 잡은 채 다른 손가락으로 점프해도 서로 입력을 빼앗지 않습니다.
- 퀴즈·도착·일시정지 중에는 버튼이 숨고 점프가 초기화됩니다. 카메라는 점프 높이를 따라가지 않으며, 착지 때 자전거만 짧게 눌립니다.
- 낮은 장애물(안전콘·상자·나무판·우유 상자)은 점프로 넘을 수 있고, 펜스는 넘을 수 없습니다. 충돌 시 기존과 같이 잠시 감속만 됩니다.
- 점프용 장애물은 `data/delivery-game.ts`의 `jump-*` 항목입니다. `span: 3`은 세 차선 전체를 막는 점프 필수 장애물입니다. 시작 직후·골목 진입/출구·우회 구간·목적지 직전에는 두지 않으며 `scripts/test-delivery-jump.ts`가 이를 검사합니다.
- 점프 높이·체공 시간·장애물별 통과 높이: `components/delivery/delivery-jump.ts`.

## 수정 위치

- `components/delivery/DeliveryJoystick.tsx`: 포인터 소유·캡처·해제와 손잡이 표시
- `components/delivery/delivery-joystick.ts`: `JOYSTICK_CONFIG`의 손잡이 이동 반경, 중앙 여유 영역, 차선 변경/재활성화 임계값
- `components/delivery/DeliveryGame.module.css`: `.playArea`, `.joystickControls`, `.joystickVisual`, `.joystick*`의 입력 범위·크기·투명도
- `components/delivery/DeliveryGame.tsx`: 기존 입력 상태에 조이스틱 연결

검증: `pnpm exec tsx scripts/test-delivery-joystick.ts`는 순수 입력 규칙을 검사합니다. `node scripts/qa-delivery-game.mjs`는 실제 브라우저 터치와 마우스로 입력·취소·대각선·추가 손가락 격리를 확인하고, 세 집 배달·우회·완료·재시작까지 진행합니다. 모바일 크기 에뮬레이션 검증이며 실제 iOS/Android 기기 검수와는 구분합니다.
