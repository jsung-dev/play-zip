# 배달 조작 (스와이프)

조이스틱과 후진을 없애고, 주행 화면 전체를 하나의 입력 면으로 씁니다. 자전거는 항상 앞으로 갑니다. 도로·카메라 설정·브랜드·충돌·진입로·배달 규칙은 변경하지 않습니다.

- **좌우로 밀기:** 인접한 한 차선으로 이동합니다. 한 번에 길게 끌면 이어서 여러 차선을 옮깁니다.
- **위로 밀기 또는 탭:** 점프합니다. 점프는 높이 1.5m·체공 0.75초입니다.
- **아래로 밀기:** 0.7초 동안 숙입니다. 낮게 가로지르는 가로대(`overhead`)는 숙여야 지나가고, 서 있거나 점프하면 부딪힙니다. 점프 중이거나 숙이는 중에는 다른 동작이 무시됩니다.
- **PC:** 화살표 좌우=차선, 위·스페이스=점프, 아래=숙이기.
- 밀기 판정은 손가락이 26px 이상 움직였을 때입니다(`components/delivery/delivery-swipe.ts`). 그보다 덜 움직이고 떼면 탭(점프)입니다. 판정 후에는 시작점이 손가락 위치로 옮겨집니다.
- 시작·일시정지·퀴즈·구매 광고 화면에서는 입력 면이 꺼집니다. 입력 면은 길안내 아래 주행 화면에만 있어 상단 버튼을 가로채지 않습니다.
- 후진은 없습니다. 세 갈래길(495m)은 왼쪽·가운데·오른쪽 모두 지나갈 수 있습니다. 갈림길 앞에서 서 있던 차선이 갈 길을 정합니다.
- 배달은 골목에 들어가지 않습니다(`components/delivery/delivery-driveby.ts`). 집 90m 전부터 "곧 배달지 도착입니다"가 뜨고, 자전거가 자동으로 감속해 집 옆 정해진 지점에 멈추면 바로 퀴즈가 열립니다. 퀴즈를 맞히면 택배가 집으로 날아가고 배달 완료입니다. 점프 같은 조작은 필요 없고, 지나쳐서 못 하는 일도 없습니다.
- 숙이기 장애물 위치: `data/delivery-game.ts`의 `duck-overhead-*`(314·880m). 숙인 자세는 `DeliveryScene3D.tsx`에서 몸을 낮추고 앞으로 기울여 보여 줍니다.


- **코스 구성**(`data/delivery-game.ts`, `components/delivery/delivery-movers.ts`, `components/delivery/delivery-course.ts`): 구간마다 한 가지 패턴만 두고, 서로 다른 장애물은 같은 길에서 10m 이상 떨어뜨립니다(`scripts/test-delivery-course.ts`가 검사). 들어설 때 구간 이름이 뜹니다.
  - 1구간 점프 연습(108–134m): 전 차선 판자 → 두 차선 상자 → 한 차선 콘.
  - 2구간 지그재그(202–215m): 오른쪽 두 차선, 이어서 왼쪽 두 차선(왼쪽은 넘을 수 없는 펜스)을 막음.
  - 3구간 차단기와 무너진 도로(258–301m): 내려왔다 올라가는 차단기(내려와 있으면 점프로 넘거나 기다림), 양쪽 콘이 가운데 점프대로 몰아 줌.
  - 4구간 움직이는 바리케이드(326m): 세 차선을 좌우로 오가는 펜스. 점프 불가, 빈 차선 타이밍을 봐야 함.
  - 5구간 연속 허들(402·419m): 착지 직후 바로 다시 뛰어야 하는 전 차선 판자 두 개.
  - 6구간 우회로(양쪽): 옆 차선으로 굴러오는 우유통 두 개가 가운데 점프대로 몰아 주고, 착지 뒤 한 차선 상자.
  - 7구간 버스(700–762m): 버스가 3차선으로 들어오는 동안 1·2차선 상자와 1차선 콘.
  - 8구간 떨어지는 택배(842m): 다가가면 그 순간 내 차선 위로 상자가 떨어집니다. 그림자가 먼저 커지니 차선을 바꾸거나 점프. 떨어진 상자는 그대로 남습니다.
  - 마지막(905·926m): 고양이와 오리 가족(엄마+새끼 5마리)이 처음부터 계속 길을 왕복합니다. 지나갈 타이밍을 맞추거나 점프.
  - 버스·택배·우유통은 다가가면 움직이고, 차단기·바리케이드·고양이·오리는 게임 시작부터 계속 움직입니다. 멈춰 있는 자전거는 부딪히지 않습니다.
- **별점**: 완료 화면 별은 부딪힌 횟수(붕괴 구간 추락 포함)와 배달 수로 정합니다. 0~1번이고 4곳 모두 배달하면 ★3, 4번 이하면 ★2, 그 외 ★1. 이 판의 기록일 뿐 포인트·보상이 아닙니다.
- **손맛**: 점프로 장애물·움직이는 장애물을 넘으면 "좋아!"와 반짝임, 점프대 착지는 "착지 성공!". 부딪히면 "앗! 부딪혔어요", 자전거 휘청임과 먼지. 장애물은 둥근 모서리의 밝은 색으로 25% 높고 깊게(폭은 그대로).
- **색감**: 톤매핑을 Neutral로 바꾸고(ACES는 파스텔을 회색빛으로 만듦) 노출·하늘·안개·조명을 밝게 조정했습니다. 건물 형태는 그대로입니다.
- 점프는 높이 1.5m·체공 0.75초입니다.
- **우유 부스터**(`components/delivery/delivery-pickups.ts`): 길 위에 우유병 6개(160·455·735·897m, 우회로 각 618m). 지나가면 3초간 최고속도 1.35배, 시야 확대·진한 속도선, "우유 부스터!" 표시. 부딪히면 즉시 끝납니다. 이 판 안에서만의 효과이며 포인트·보상이 아닙니다.
- **도로 붕괴 + 점프대**: 283m, 우회로 양쪽 590m, 864m에 길 전체(모든 차선)가 무너진 17m 구간이 있고, 바로 앞 가운데 차선에만 점프대가 있습니다. 32m 앞 표지판이 "가운데 점프대로"를 알려줍니다.
  - 점프대를 밟으면 속도를 19~21m/s로 맞추고 공중에서는 그대로 유지해, 항상 약 20m를 날아 같은 자리에 착지합니다. 일반 점프(최고속도 15m)로는 못 건넙니다.
  - 점프대 비행 구간과 착지 후 8m에는 다른 장애물·움직이는 장애물을 두지 않아, 점프대로 장애물을 건너뛰지 않습니다(`scripts/test-delivery-pickups.ts`에서 검사).
  - 점프대를 못 타고 붕괴 구간에 들어가면 자전거가 빠지고 약 1초 뒤 구간 16m 앞 가운데 차선에서 정지 상태로 다시 시작합니다.
- 손맛 연출: 최고속도 근처에서 시야가 아주 조금(2.5°) 넓어지고 화면 가장자리에 옅은 속도선이 나타납니다. 충돌 때만 화면이 살짝 내려앉았다 돌아옵니다(착지 흔들림은 덜컹거림이 강해 제거).
- 장애물에 부딪히면 속도가 60%로 줄고(기존 38%), 1초간 최고 11m/s로 제한됩니다(기존 7.5m/s). 장애물이 늘어난 만큼 멈칫거림을 줄였습니다. 기기의 "동작 줄이기" 설정이 켜져 있으면 시야 변화·흔들림을 하지 않습니다.
- 소리·진동(`components/delivery/delivery-sound.ts`): 점프·착지·충돌·배달 효과음과 가벼운 배경음을 코드로 합성합니다(음원 파일·라이선스 없음). 진동은 지원하는 기기(주로 안드로이드)에서만 됩니다. 기본은 켜짐이고, 일시정지 메뉴의 "소리·진동" 버튼으로 끄면 이 기기에 저장됩니다. 브라우저 정책상 소리는 우유 카드를 누른 뒤부터 납니다.
- 모바일 주소창이 나타나거나 사라질 때 생기는 화면 높이 변화로는 조작을 끊지 않습니다. 화면 폭이 바뀔 때(회전)만 초기화합니다.
- 점프 높이·체공 시간, 장애물별 통과 높이는 `components/delivery/delivery-jump.ts`, 점프용 장애물 배치는 `data/delivery-game.ts`의 `jump-*` 항목입니다.

## 수정 위치

- `components/delivery/DeliverySwipe.tsx`: 전체 화면 입력 면(포인터 캡처·탭·밀기)
- `components/delivery/delivery-swipe.ts`: 밀기 임계값과 방향 판정
- `components/delivery/delivery-jump.ts`: 점프·숙이기 시간, 장애물별 통과 조건
- `components/delivery/DeliveryGame.tsx`: 자동 전진, 입력 연결, 숙이기 충돌 판정
- `components/delivery/DeliveryGame.module.css`: `.swipePad`

검증: `pnpm exec tsx scripts/test-delivery-swipe.ts`가 밀기 판정과 숙이기 규칙을 검사합니다.


## 화면 UI (시작·퀴즈·결과·일시정지·상단 안내)

- 공통: 흰 카드 + 위쪽 동네 일러스트(`DeliveryArtUi.tsx`, 인라인 SVG) + 민트/초록 강조색. 버튼은 높이 52px 이상.
- 시작: "우유를 골라 주세요" — 우유 카드 3개 중 하나를 누르면 바로 출발, `뒤로 가기`(플랫폼).
- 퀴즈: 같은 우유 카드 3개로 답을 고름. 오답은 빨간 테두리·흔들림과 "다시 골라 볼까요?".
- 결과: 별(부딪힘 기준) + 배달 수/부딪힘 칩 + 광고 예시 카드(체험용, 실제 결제 없음) + `다시 하기`/`뒤로 가기`.
- 일시정지 = 설정: 다음 배달지, 이동하는 손(오른손/왼손), 소리·진동 스위치, `계속 배달하기`, `길 안내`, `처음으로`, `게임 나가기`.
- 상단 안내: 방향 아이콘 타일 · 안내 문구/목적지 · 남은 거리 · 일시정지 버튼, 아래에 배달 진행 막대. 높이(카메라 여백)는 그대로.

## 장애물·갈림길 (최신)
- 새 위험: 증기 분출구(경고 후 분출, 차선 3개를 동시에 막지 않음), 차선 차단기(항상 한 차선은 열림), 장바구니 카트, 떨어지는 화분·수박(소포와 함께 조준/고정 차선). 정적 장애물도 본길 위주로 늘렸고, 좌·우 갈림길은 서로 다른 구성입니다.
- 골목 3 출구(858) 뒤 점프대는 896m로 옮겼습니다(출구 38m 이후). `test-delivery-pickups`가 모든 출구 −40~+35m 안에 본길 점프대가 없는지 검사합니다.
- 갈림길 선택은 분기점 + 36m(`FORK_SWITCH_METERS`) 안이면 가운데에서 나와도 바로 좌/우로 전환됩니다.
