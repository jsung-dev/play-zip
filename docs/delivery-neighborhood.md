# 동네 건물·바닥·최종 배너

## 건물

`components/delivery/three/street-architecture.ts`에서 참고 시트의 A~E 다섯 유형을 실제 3D 도형으로 생성합니다.

| 유형 | 층수 | 형태 |
| --- | --- | --- |
| A / apricot-shop | 3 | 낮고 넓은 살구 상가, 긴 상층 창, 크림 차양, 낮은 옥탑 |
| B / mint-villa | 6 | 왼쪽 큰 창 + 오른쪽 1.05 깊이의 실제 발코니, 층별 크림 띠, 측면 창 두 개, 옥상 4면 난간 |
| C / cream-tower | 7 | 좁고 높은 크림 빌딩, 연속된 세로 계단실 유리, 오른쪽 작은 창·난간 |
| D / lavender-house | 5 | 라벤더 주택, 넓은 창과 홀수 층 돌출 발코니, 실외기, 옥탑·난간 |
| E / yellow-shop | 3 | 넓은 연노랑 상가, 분리된 상층 창 3개, 민트 차양, 낮은 옥탑 |

창문 자체를 세로로 늘리지 않고 층별로 배치합니다. `building-facade.ts`에서 다섯 외벽색, 청색 유리, 두께가 있는 크림 창틀, 발코니, 차양, 옥상 화단을 공유합니다. 특히 주행 방향에서 크게 보이는 양쪽 끝면도 유형별로 다릅니다. 새 로고·상호는 없습니다.

2026-10 시안 반영: 층수를 3~7층으로 높이고, 창마다 하늘빛 그라데이션 유리와 층마다 다른 반쯤 친 커튼, 상가 유리의 따뜻한 실내빛, 상가 앞 화분, 옥상 나무, 일부 창 아래 꽃 화분을 넣었습니다. 처마·발코니 밑면, 건물 아랫부분, 측면은 정점 색에 미리 어둡게 구워 넣어(`shadeFacade`) 실시간 그림자 없이 입체감을 줍니다.

`scene-art.ts`의 `buildingBox()`는 모든 외벽 색을 **정점 색 하나의 재질**로 공유합니다. 그래서 36m 구역 하나가 색 수만큼이 아니라 한 번에 그려집니다. 색상의 42%를 보조광으로 더하는 기존 표현(`emissiveIntensity: .42`)은 셰이더에서 정점 색으로 그대로 유지하고, `toneMapped: false`도 같습니다. 두께 .03 이하의 얇은 면(유리·커튼·실외기 살)은 앞면 사각형 하나로 만듭니다. 추가 실시간 조명·그림자 맵·반사·후처리는 없습니다. 기존 태양·환경광·카메라, 광고면과 배달함 재질은 변경하지 않았습니다. 발코니 안쪽 면에 차분한 명암색을 사용해 실제 빈 공간의 깊이를 보여줍니다.

`street-layout.ts`의 `buildingProfile(item, true)`는 **기존 부지의 예약 외곽**입니다. 높아진 건물을 위해 높이 배율만 1.8 → 3으로 올렸고, 배치기는 광고 시야를 그대로 다시 검사합니다. 결과 부지 수는 203개로 같습니다. 실제 새 모델은 이 외곽 안에서만 만들어집니다. 배달 대상 집과 실제 출입구는 기존 모델을 사용합니다.

광고 설치 건물은 `advertisement-building.ts`에서 별도로 생성합니다. 기존 큰 광고면의 위치·크기·텍스처·프레임은 그대로 두고 그 뒤의 건물만 낮은 유리 상가와 옥상 구조로 변경했습니다. `outdoor-ad-model.ts`는 이 건물만 연결합니다.

10개 조합의 템플릿을 공유하고, 기존 36m 구역별 병합·거리별 숨김을 유지합니다. 일반 건물 전체의 삼각형 합은 430,990 → 약 561,000개(층수 증가로 +30%), 구역 병합 전 메시는 2,243 → 406개입니다. 헤드리스 브라우저(390×769)의 같은 위치에서 한 프레임 드로콜은 60m 379 → 174, 250m 392 → 190, 화면 삼각형은 168k → 200k, 174k → 208k였습니다. 실기기 FPS 측정값은 아닙니다.

## 바닥

`road-surface.ts`의 주행 아스팔트는 `#929A9C`, 버스 전용 측면 공간과 공사 차단 구간은 `#C7BCAB`, 보도는 `#F5F0E5`입니다. 잔디와 흰색 차선은 유지합니다.

`scene-builders.ts`에서 추가 차선 끝단의 아스팔트 경계를 부드럽게 좁혀 큰길에 연결합니다. 골목 입출구의 장식용 7.6m 벌어짐은 추가 차선과 같은 3m 입구에서 4.4m 골목 폭으로 이어지는 마감으로 바꿨습니다. 실제 경로 좌표·조작·충돌·출입 판정은 바꾸지 않았습니다.

## 최종 목적지 배너

`data/delivery-outdoor-ads.ts`의 `DESTINATION_OVERHEAD_AD`: 975m, 가로 14, 세로 3.5(4:1), 중심 높이 9.2. 지주는 주행로와 버스 측면 차로 밖에 있습니다. 광고 아래는 비어 있어 주행·카메라·목적지 입구를 막지 않습니다.

`image: null`이면 ‘광고주 구함’입니다. 기존 옥외 광고와 같은 로딩·실패 대체·비율 유지 구조를 공유하며, 이미지 교체는 [옥외 광고 문서](delivery-outdoor-ads.md)를 따릅니다. 배달함 브랜드 설정과는 독립적입니다.

## 주행 끊김 대응 (2026-10)

- `DeliveryScene3D`는 게임 런타임(`runtimeRef`)을 매 프레임 직접 읽습니다. React 재렌더를 기다리지 않으므로 화면 위치가 한 프레임씩 밀리거나 건너뛰지 않습니다. 주행 중 HUD 재렌더는 초당 약 12회로 줄였습니다(상태 전환·입력은 즉시 반영).
- 3D 장면을 만들 때 모든 구역을 한 번 그려 GPU에 미리 올립니다. 달리다가 새 구역이 처음 보일 때의 업로드 멈춤을 시작 화면에서 미리 치릅니다.
- 픽셀 비율 상한 1.75 → 1.5. 고해상도 폰에서 채우기 부담을 약 27% 줄입니다.
- 자전거의 움직이지 않는 부품을 재질별로 묶어 자전거 드로콜 108 → 39. 바퀴·페달·다리는 따로 움직입니다.
- 도로는 변경하지 않았습니다.
- 실기기 FPS는 측정하지 않았습니다. 폰에서 체감을 확인해야 합니다.
